Enter your gateway token and payer mobile to start.

The API token is sent directly to the gateway from this browser and can be exposed on this device. Use a rotated, restricted test token only. The page does not save the token. A ₹1 payment can debit real money.

The supplied integration guide documents a return URL and status polling, not a webhook. A webhook must be a server endpoint that accepts gateway callbacks; this page URL is not one. Browser API calls also require the gateway to allow this website's origin with CORS. If the gateway blocks CORS, a server-side proxy is required; the page will report that the status could not be read rather than incorrectly reporting payment failure.
