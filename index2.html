Gateway payment

Create a checkout, pay on the gateway page, then check the gateway status here.

Open checkout

Enter the payer mobile to start. The gateway token is configured privately on the server.

A ₹1 payment can debit real money. The API token is kept on your hosting server and is not sent to the browser.

The supplied integration guide documents a return URL and status polling, not a webhook. A webhook must be a server endpoint that accepts gateway callbacks; this page URL is not one. Upload both this page and gateway-proxy.php to the same HTTPS folder. The PHP proxy calls the gateway server-to-server, so browser CORS restrictions do not block the API response.
